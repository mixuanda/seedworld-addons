# SeedWorld Add-ons

This repository hosts the SeedWorld add-on registry and documentation for managing add-on manifests.

## Registry

- `manifests/index.json` — add-on index
- `manifests/whispercpp/manifest.json` — whisper.cpp add-on manifest
