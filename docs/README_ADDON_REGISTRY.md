# SeedWorld Add-on Registry

Use this registry URL in SeedWorld to discover available add-ons:

```
https://raw.githubusercontent.com/mixuanda/seedworld-addons/main/manifests/index.json
```

## Update strategy

1. Edit or add manifest files under `manifests/`.
2. Commit the changes to the `main` branch.
3. SeedWorld will read the updated registry from the raw GitHub URL above.
